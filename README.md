# DSA Java Solutions

A structured collection of Java solutions for DSA practice from Weeks 3–10.

## Structure
- `Week01_General/` - Core OOP, exception handling, sliding window, two pointers
- `Week03_Arrays/` - Sliding window, ArrayList, matrices, index negation, LeetCode
- `Week04_Searching/` - Sliding window, searching, binary-search variants, LeetCode
- `Week05_Sorting/` - Bubble, Selection, Merge Sort, LeetCode sorting
- `Week06_Backtracking_Recursion/` - Quick Sort, subsets, House Robber, phone combinations
- `Week07_Recursion/` - Binary Watch and recursion patterns
- `Week08_LinkedList/` - Singly and doubly linked lists
- `Week09_CircularLinkedList/` - Circular linked list operations
- `Week10_LinkedList_LeetCode/` - Linked-list LeetCode problems

Each problem is stored in a separate `.java` file.
